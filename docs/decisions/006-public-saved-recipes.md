# ADR-006: 공개 프로필의 저장한 맛 표시

## 배경

다른 사람 프로필에도 저장한 레시피 수와 저장한 맛 탭이 필요하다. 사용자는 저장 목록을 기본 공개로 결정했다. 기존 `GET /api/profiles/:id`는 공개 레시피를 작성한 전승자만 반환한다.

## 결정

기존 응답에 `saved_recipe_count`와 `saved_recipes`를 추가한다. 게시·공개 상태인 레시피만 포함하고 저장 시각 역순으로 반환한다. 공개 레시피를 작성하지 않은 프로필도 조회할 수 있게 한다. 인증 요구는 유지한다.

## 검토한 대안

- 저장 수만 공개: 응답이 작지만 저장한 맛 탭을 구현할 수 없다.
- 별도 저장 목록 API: 페이지네이션에 유리하지만 현재 UI에 필요한 API가 늘어난다.

## 선택 이유와 결과

기존 프로필 요청 한 번으로 두 탭을 구성할 수 있다. 저장 목록이 많으면 응답 크기가 늘어날 수 있으므로 실제 사용량을 측정한 뒤 별도 페이지네이션 API를 검토한다. 비공개·미게시 레시피는 저장돼 있어도 공개 응답에서 제외한다.
