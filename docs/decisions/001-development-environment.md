# 001. 한술 개발 환경과 파일 업로드 계약

해커톤 데모에서 음성, 사진, 스트리밍 API를 한 프로젝트에서 개발해야 한다. Vercel 함수 본문 크기 제한 때문에 앱 서버가 대용량 파일을 직접 받는 구성은 데모의 파일 제한과 맞지 않는다.

Next.js 16 Route Handlers와 TypeScript를 사용한다. Supabase는 인증, PostgreSQL, 파일 저장을 맡는다. 파일은 Supabase 서명 업로드로 전송하고 API에는 파일 경로만 보낸다. 서버는 사용자와 파일 권한을 확인한다. Claude와 OpenAI 연동 키는 서버 환경변수로 관리한다.

별도 서버와 서버 경유 업로드도 검토했다. 단일 프로젝트는 초기 통합 부담이 적고, 직접 업로드는 앱 서버의 요청 본문 제한과 파일 크기를 분리한다.

이 변경에는 개발 환경과 계약 문서가 포함된다. 실제 API 구현, Storage 정책 배포, 데이터베이스 스키마 적용은 후속 개발에 포함된다.
